# Part 3 code

Standard library Python 3.9+. Nothing to install.

```bash
python3 -m unittest discover tests -v   # self-check
python3 semantic_entropy.py             # driver, prints the four AUROCs
```

## Files

| File | What |
|---|---|
| `semantic_entropy.py` | Fill in the `TODO` functions. Tasks 1 to 3. |
| `buggy_metrics.py` | Inherited code. Audit it. Task 5. |
| `tests/test_public.py` | Self-check. Add your own tests here. |
| `data/generations.json` | 300 examples: generations, log probs, entailment matrix, label. |
| `data/toy_cases.json` | Four hand-checkable cases with known answers. |

Add `RESULTS.md` (Tasks 4 and 6) and `AUDIT.md` (Task 5) to this directory.

## Data notes

Synthetic, generated by `tools/generate_fixtures.py`, which documents the
process. Not real model output.

Fields starting with `_` are latent ground truth for auditing. Do not use them
in Tasks 1 to 3. Task 6 uses them on purpose.

The entailment matrix is **directed**: `entailment[i][j] == 1` means generation
`i` entails generation `j`. It is not symmetric and the relation it encodes is
not transitive.
